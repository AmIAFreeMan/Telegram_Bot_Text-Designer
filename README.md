# Telegram Text Designer Bot

A lightweight, interactive Python Telegram bot built with **aiogram** that takes user text and transforms it into stylish Unicode font variants (Bold Serif, Cursive Script, and Monospace).

---

## Features
* **Interactive FSM Workflow:** Guides users step-by-step from text input to style selection using Telegram inline keyboards.
* **Unicode Font Styling:** Converts plain text into alternative mathematical/alphanumeric character sets.
* **Localized UI:** Clean Russian-language interface.
* **Secure Configuration:** Uses environment variables (`.env`) to keep API tokens safe.

---

## Prerequisites
* Python 3.10 or higher
* A Telegram Bot Token (obtained from [@BotFather](https://t.me/BotFather))
